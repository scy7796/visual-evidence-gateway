## Short description (all sites)

Local, read-only MCP server for text-first agents: focused image questions return compact, checked visual evidence at about 1/10 the context of native attachment.

## mcp.so

- Name: visionsieve
- Repository: https://github.com/scy7796/visionsieve-mcp
- Category: Vision / Image
- Description: one tool, vision.inspect(paths, query). Copies approved images to a private directory, calls a pinned model through the local Codex CLI, validates the response schema and evidence references, and returns a compact evidence packet. The default route uses the existing ChatGPT login; no API keys, no silent model fallback.
- Install command: `codex mcp add visionsieve -- visionsieve serve`
