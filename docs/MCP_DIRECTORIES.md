## Short description (all sites)

Local, read-only MCP server for text-first agents. Focused image questions return compact, checked visual evidence at about 1/10 the context of native attachment.

## mcp.so

- Name: visionsieve
- Repository: https://github.com/scy7796/visionsieve-mcp
- Category: Vision / Image
- Description: one tool, vision.inspect(paths, query). It copies approved images to a private directory, calls a pinned model through the local Codex CLI, validates the response, and returns a compact evidence packet. The default route uses the existing Codex ChatGPT login; no API keys are stored and there is no silent model fallback. Path allowlist, no symlinks or reparse points, read-only backend process.
- Install command: `codex mcp add visionsieve -- visionsieve serve`
